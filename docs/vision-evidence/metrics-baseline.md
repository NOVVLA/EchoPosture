# 视觉统一指标基线

- 状态：协议冻结，数值待采集
- 关联任务：EP-VISION-003
- 适用模式：兼容、标准候选、专业候选

## 计时和采样约定

- 使用单调时钟；采集帧到达、推理开始、推理结束、身份事件开始和事件收敛时间戳。
- 姿态延迟从“推理开始”到“统一人物观测可用”；不把摄像头等待或 UI 绘制混入模型延迟。
- 端到端事件延迟从触发事件的第一帧到身份状态稳定为 `MATCH`、`MISMATCH` 或 `UNCERTAIN`。
- 每个模式、输入分辨率和后端至少运行 60 秒热身后再采样 5 分钟；报告样本数和丢帧数。
- 同一录像集、同一场景顺序和同一阈值用于 A/B 比较；禁止只报告平均值。

## 指标定义

| 指标 ID | 名称 | 定义 | 报告 |
| --- | --- | --- | --- |
| `pose_fps` | 姿态处理频率 | 有效统一观测数 / 观测窗口秒数 | P50、P95、均值 |
| `pose_latency_ms` | 姿态延迟 | 单次姿态推理耗时 | P50、P95、最大值 |
| `identity_latency_ms` | 身份事件延迟 | 事件触发到三态稳定耗时 | P50、P95、失败数 |
| `target_id_switches` | 目标 ID 切换数 | 同一场景中 `target_track_id` 变化次数 | 总数；静默切换数必须为 0 |
| `recapture_time_ms` | 重新捕获时间 | 原目标重新出现到身份状态稳定的耗时 | P50、P95、超时数 |
| `false_accept_rate` | 误接受率 | 旁人/换人片段被判为目标的次数 / 相关片段数 | 分场景和总计 |
| `false_reject_rate` | 误拒绝率 | 目标片段被判为不匹配的次数 / 相关片段数 | 分场景和总计 |
| `multi_user_safety` | 多人安全结果 | B 出现、交叉、遮挡、A 离开时是否保持 A 目标或安全不确定 | 每场景通过/失败 |

## 最小场景矩阵

每个模式至少覆盖以下标签：`single_user`、`second_person_enters`、`parallel_motion`、`occlusion`、`crossing`、`target_leaves`、`target_returns`、`seamless_replacement`、`head_turn_glasses_lighting`、`calibration_second_person`。

## 首轮门槛

这些是比较门槛，不是已经测得的事实：

- 标准模式姿态处理目标不低于 8 Hz，争取稳定 10–15 Hz；
- 专业模式参考设备目标不低于 20 Hz，以 P95 延迟决定 l/x 和分辨率；
- 关键身份事件在质量足够时约 2.5 秒内收敛；
- 所有场景的静默目标切换数为 0；
- 重型身份验证不得阻塞 UI 或姿态工作线程。

报告必须同时列出硬件、驱动、Python/Runtime 版本、模型文件 SHA-256、后端、分辨率、阈值、样本数和未验证项。
