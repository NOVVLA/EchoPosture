# 视觉证据资产

本目录只保存可审计的元数据和指标，不保存真实摄像头帧。真实录像不得提交到 Git；默认保存在受控的本地测试目录，完成测试或到期后按删除日志销毁。

## 当前状态

- `recording_manifest.csv` 目前只有字段表，没有已登记录像。没有参与者同意记录时，录像集状态为 `BLOCKED`。
- `deletion_log.csv` 用于记录每个资产的删除请求、执行时间、执行者和校验结果；不能用“文件已不存在”替代删除记录。
- `metrics-baseline.md` 冻结指标名称、计时边界、场景标签和报告格式；当前没有真实测量值。
- `benchmark-synthetic-p3-p4.jsonl` 是不含图像的合成观测矩阵，用于验证状态序列；可用
  `runtime\\python311\\python.exe vision_replay.py docs\\vision-evidence\\benchmark-synthetic-p3-p4.jsonl` 重放。
- 真实图像、视频、人脸裁剪、身份模板和向量不得进入仓库、日志、崩溃报告或发行包。

## 参与者同意和保存规则

录制前必须取得可追溯的书面或电子同意，至少说明：用途仅限 EchoPosture 本地回放测试、采集场景、是否包含旁人、保存位置、保存期限、删除方式、联系人和撤回方式。未成年人或无法代表他人同意的旁人不得录入。

默认保存期限为测试完成后 30 天，或者参与者撤回后 72 小时内，以较早者为准。发现无意录入旁人、敏感画面或无法证明同意时，立即隔离并删除，不得继续分析。

允许的资产类型只有：

- 原始视频：受控本地目录，访问权限限于测试人员；
- 派生回放索引：只含时间戳、场景标签和模型输出，不含图像；
- 指标汇总：只含聚合数字，不含可逆身份信息。

## 录制和删除流程

1. 录制前为每名参与者生成不可识别的 `participant_id`，签署同意并登记保存截止日。
2. 录制完成后计算 SHA-256，将文件路径、大小、场景标签和同意记录位置写入清单；清单不写姓名。
3. 回放只读取受控目录；工具和日志禁止复制帧、裁剪或向量。
4. 测试完成、到期或撤回时，停止所有读取进程，删除原始和派生文件，重新扫描目录并在删除日志记录结果。
5. 任何备份、临时目录或回收站副本都必须一并核查；删除未完成时状态保持 `BLOCKED`。

## 提交前检查

- `recording_manifest.csv` 每行都有同意状态、保存截止日和 SHA-256；
- `deletion_log.csv` 覆盖已删除或撤回的资产；
- `git status --short` 不显示真实媒体文件；
- 发行扫描确认没有视频、图片、模板、向量或包含这些内容的日志。
